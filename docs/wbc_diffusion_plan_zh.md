# White Blood Cell Diffusion Model 研究计划（修订版）

## 项目目标

### 当前阶段目标：无条件图像生成

训练一个无条件 DDPM，学习单个白细胞（WBC）图像的图像分布，生成可辨认的白细胞图像，为后续条件生成建立可复现的模型和评估基线。本阶段输入只有图像，不向模型输入细胞类型、疾病诊断或形态属性标签。

本阶段**只研究图像分布建模和合成样本质量**。目标是判断模型能否生成外观上可辨认、具有合理变化且不明显复制训练图像的 WBC 图像。

本阶段的目标不包括：

- 生成可用于临床诊断或临床决策的疾病图像；
- 证明模型学习或发现了细胞病理机制；
- 将合成细胞解释成真实患者、疾病亚型或生物学因果过程的代表。

“无条件”表示采样时不指定类别或疾病条件；它不表示忽略数据质量、来源、标签审计和数据拆分。数据中的类别目录可用于质量控制、分层统计和生成结果的事后分析，但不能作为本阶段模型输入。

### 后续研究目标

只有无条件基线通过预先定义的质量与多样性门槛后，才开展条件生成。细胞类型、可测形态属性和疾病组别是不同的条件任务，分别需要可靠的细胞标签、细胞级形态标注或患者级诊断及其关联信息。疾病条件结果仍只能支持数据标签所允许的图像分布关联，不自动构成病理机制或临床有效性的证据。

## 推荐数据策略

1. **本阶段主数据：**使用 Raabin-WBC cropped double-labeled 的 Train 组件中通过质量控制的单细胞图像。保留官方类别目录和原始文件；不把类别、疾病或形态标签传给无条件模型。
2. **无条件基线按原始训练分布采样：**首个基线保留合格图像的自然类别比例，避免把人为类别平衡误当成数据本身分布。另做均衡采样只能作为明确标注的敏感性实验，并与自然比例基线分开报告。
3. **数据拆分：**先查明患者/玻片/采集批次标识并识别重复簇，再冻结训练、验证、测试清单。同患者/玻片或重复簇不得跨集合。若标识无法确认，必须把无法保证患者级隔离写入限制；不可将文件名猜测为患者 ID。
4. **外部评估：**Acevedo v1 先保持独立。只有数据条款和配对标签核实后，才用于真实图像外部参考；不将其混进 Raabin 首个基线。
5. **未来条件实验：**细胞类型条件可作为第一项条件任务；形态属性条件需要可信分割或细胞级标注；疾病条件需要疾病标签与患者/图像的可靠映射，并按患者分组拆分。

## 分阶段计划

### 阶段 0：已下载数据核验、数据治理与任务定义

- **已完成：**`Train.rar`（292,300,976 bytes）的 SHA-256 已核验，归档已安全解压；现有 inventory 记录了 10,175 张 JPEG，均可解码，尺寸均为 575×575 RGB。下载来源、HDD 路径和校验信息记录在 `datasets/metadata/dinobloom/raabin-wbc-train-source.json`。原图按只读方式使用。
- **待完成：**再次核对 inventory 与当前文件清单；补充图像哈希、重复检测、图像质量审核及许可/引用要求。当前没有证据表明已完成患者/玻片分组核验或人工 QC。
- 完成逐图 manifest：相对路径、文件大小、SHA-256、解码状态、尺寸、通道、原始类别目录、来源、可确认的患者/玻片/批次标识、重复簇、质量标记、排除原因和数据拆分。
- **分开评估图像质量与类别标签质量。**若图像是清晰可辨的 WBC，但文件夹类别可能标错，可保留用于无条件图像建模，同时把标签标为待复核/未知；不能将不确定标签用于未来条件训练或分类评估。
- 先对全量图像做确定性技术检查：文件可解码、尺寸/通道、异常像素、空白/极暗/极亮图像、清晰度与边界截断提示；自动指标只用于筛查，不能单独判定生物学可用性。
- 按类别生成可追溯的缩略图页，先均衡抽样目视检查，再重点查看自动筛出的异常图和随机抽查通过图。建立 `keep / review / exclude` 规则及理由；红细胞作为血涂片背景本身不构成排除理由。
- **图像保留标准：**可辨认一个主要 WBC 目标；细胞及关键内部结构没有严重裁断、模糊、遮挡或损坏；染色/照明没有严重到妨碍细胞辨认。多目标、严重失焦、非细胞图像、严重伪影或文件损坏列为复核/排除。可用性判断不以模型生成效果倒推。
- 使用强文件哈希识别精确重复，再用感知哈希/特征近邻找近重复；人工核对候选重复簇。现有 inventory 未做哈希，须补做。
- 确认 Train 组件与官方 TestA/TestB 的关系及可用条款。当前仅记录 Train 组件；正式报告若没有官方留出集，明确说明内部验证/测试集的构造方式。
- **输出：**数据卡和许可记录、全量 manifest、图像/标签 QC 决策表、重复簇报告、类别计数（原始与 QC 后）、样本缩略图页、冻结的拆分文件和预处理配置。

### 阶段 1：无条件 DDPM 最小基线

#### 1.1 研究问题

- 在固定来源、固定拆分和固定预处理下，像素空间 DDPM 能否从随机噪声生成外观可辨认的单个 WBC 图像？
- 生成图像是否具有足够的样本变化与类别覆盖，或只重复多数类/少数典型外观？
- 分辨率、训练进度和数据质量如何影响细胞边界、细胞核、胞质及背景的可辨认程度？
- 生成图像是否出现训练样本复制、严重伪影或明显偏离训练图像分布的现象？

模型学习的是训练图像中的像素统计和共现模式。即使生成图像出现类似细胞核或胞质的结构，也不能据此说模型理解了细胞组成或病理机制。

#### 1.2 数据输入与预处理

- 输入仅包含阶段 0 冻结清单中的 QC 合格图像；不传递类别文件夹名、疾病标签、患者诊断或形态属性。
- 首个基线按 QC 后数据的实际比例随机采样，不对稀有类重采样。训练和测试阶段事后按类别统计生成覆盖，观察不平衡对结果的影响。
- 原始图像保持只读。全部图像统一为 RGB；像素缩放至 `[-1, 1]`。不做会抹去染色差异或改写细胞形态的颜色归一化、弹性变形或随机裁剪。
- 先做 128×128 的短程 smoke run 检查代码链路；正式候选分辨率以 256×256 为主，并与 128×128 比较细胞核/边界保留、资源开销和生成质量。64×64 仅用于极低成本的流程调试，不作为默认形态学结果分辨率。任何缩放都保持方形视野，不二次裁掉目标细胞。
- 第一轮不加随机几何或颜色增强。若之后加入翻转/旋转，单独作为消融并说明其方向学假设；不与主基线混为一组。

#### 1.3 模型与训练流程

- 使用像素空间 U-Net、标准 DDPM 前向加噪与反向采样，基线预测噪声 `ε`。优先复用已检查过的实现；CIFAR-10 只验证代码实现，不作为 WBC 科学结果。
- 首次 smoke run 使用小型数据子集和较短更新数，检查 batch 输入范围、前向加噪、loss 是否有限、反向采样、checkpoint 保存/恢复和固定随机种子采样。
- Smoke run 通过后，使用冻结训练清单进行正式训练。固定并记录噪声日程、`T`、模型宽度/层数、图像分辨率、优化器、学习率、batch size、训练更新数、EMA 设置、随机种子、软件环境和硬件资源。
- 每个预设训练节点保存 checkpoint/EMA 权重、训练与验证日志，并用同一组固定 seeds 采样。不得根据测试集样本或指标选择 checkpoint。
- 输出固定尺寸样本网格及对应原图/近邻比对；记录实际训练时长、显存/内存、采样成本、失败重跑和 checkpoint 恢复结果。

### 阶段 2：无条件生成质量评估与决策门槛

本阶段评价“合成图像是否像该数据来源中的 WBC 图像、是否多样、是否过度记忆”，不评价诊断正确率或疾病机制。

- **人工盲评与错误分类：**将真实留出图像和生成图像随机混排、隐藏来源，按可辨认性、单细胞完整性、细胞核/胞质结构、背景/染色合理性、伪影严重程度评分。先定义量表和通过门槛，再查看正式结果。记录评审人数和一致性；非血液形态专家的评价应如实标注。
- **真实性/分布距离：**报告统一预处理下的 FID、KID 等指标；自然图像特征和 WBC 域特征分开报告，标明特征网络、样本数和局限。不得用单一 FID 或未验证的分类器分数宣称医学真实性。
- **覆盖与多样性：**报告特征空间 precision/recall 或 coverage、真实与生成特征分布及重复率。使用独立且适用的细胞分类器时，可事后估计生成图类别构成；分类器不可靠时以人工抽查为主。与真实 QC 后类别比例比较时，考虑自然类别不平衡。
- **结构与形态：**若有经过验证的分割器/专家标注，检查细胞占比、核质比、细胞面积、核形态等分布；自动测量须先在人类标注子集上核对误差。不得把结构指标解读为病理因果证据。
- **记忆化与重复：**对生成样本与训练集做像素哈希、感知哈希和特征近邻检索，人工核查最近邻。报告检索方法、阈值、复核数量和发现的重复/近重复个例。
- **训练稳定性：**结合训练/验证 loss、固定 seed 的跨 checkpoint 样本网格、不同 seed 的输出，检查不收敛、模式坍塌和 checkpoint 挑选偏差。Loss 下降本身不证明生成质量合格。
- **按分辨率/数据质量分层：**比较 128 与 256 候选结果；抽查 QC 不确定图像对训练效果的影响。每次只改变一个主要因素，记录完整配置。

#### 进入条件生成的门槛

开始条件模型前，团队需在正式评估前确定可操作的通过标准。至少满足：数据和许可记录完整；冻结拆分和运行可复现；盲评中多数评估者能够将样本辨认为 WBC 图像且严重伪影可控；有足够的类间/类内变化而非明显坍塌；近邻分析未显示不可接受的训练样本复制。若不满足，优先处理数据筛选、图像分辨率、拆分泄漏和训练收敛，再决定是否升级模型。

通过门槛只表示可以开始研究条件控制，不表示具备临床诊断价值。

### 阶段 3：条件生成路线（无条件基线通过后）

条件生成分为三个独立任务，按标签可信度逐步推进，不在一个实验中同时引入疾病、类别和形态条件。

#### 3.1 细胞类型条件 DDPM

- 第一类可控条件选 WBC 类型（如中性粒、淋巴、单核、嗜酸、嗜碱等，以实际标签字典为准），而非先选疾病。
- 训练 class-conditional U-Net：将类别 embedding 注入残差块/注意力层；类别标签在每个训练样本明确存在。增加少量 label dropout 后可做 classifier-free guidance（CFG）；保留无条件基线作为比较。
- 建立逐类样本数表。少数类设置分层采样或损失/采样权重，报告真实训练分布与重平衡方案，避免把过采样后的合成分布解释为自然患病率。
- 比较无条件基线、类别条件但 guidance=1、以及少量预设 guidance 强度；每次控制变量。相同总训练预算并固定评测 seeds。
- 评估：独立分类器类别命中率、真实测试特征空间的类内分布距离、每类多样性/覆盖度、错误类率、近邻记忆化、专家形态一致性。类别可辨性提升不应以不自然伪影或模式坍塌为代价。
- 可选做跨数据源迁移：Raabin 训练的条件生成图与 Acevedo 中同类图像比较，但把域偏移与类别控制分别报告。

#### 3.2 细胞形态属性条件

- 对“控制细胞某些组成的伸缩/形态”先定义可重复测量的属性，例如细胞核面积比例、细胞圆度、核分叶数或细胞/核尺寸。通过专家标注或可靠分割得到细胞级属性，并估计标注/测量误差。
- 先一次控制一个属性，固定来源和细胞类型；使用属性 embedding、FiLM 或回归式条件向量。验证目标属性与生成图实测属性是否校准、单调，并监测其他属性耦合变化、细胞类别漂移和图像伪影。
- 若属性彼此相关或测量不可靠，不声称能够独立控制，也不把“拉伸某个部件”直接解释为疾病变化。

#### 3.3 疾病组别条件生成（通过数据门槛后）

- 先选择单一、标签清楚且样本充足的任务，例如 AML vs 健康对照；具体目标取决于数据标签和导师确认，不预设任何数据必然满足门槛。
- 建立标签层级图：患者诊断 → 玻片 → 单细胞标签。只有当图像属于同一患者且有可信诊断时，才能把患者诊断作为弱监督条件，并明确模型学习的是“该患者队列中的细胞图像分布”，不等同于单细胞疾病真值。
- split 必须按患者分组；同患者/玻片及其增强副本只能落入一个集合。若患者 ID 缺失，不做严格疾病泛化主张。
- 采用分层条件（疾病组 + 细胞类型）优于单一疾病标签，前提是交叉组合有足够样本；不够时缩窄类别，不用标签泄漏或合成过采样伪造独立样本。
- 评估疾病条件一致性须用未参与生成训练的分类器/独立队列及专家盲评；同步报告类内形态多样性、队列/染色域预测、近邻记忆化。疾病预测器分数高本身不证明形态真实或疾病机制被学到。
- 结论限定为图像分布的条件关联；不能声称通过控制单一细胞部件模拟疾病因果机制。

### 阶段 4：方法比较与最终研究结论

- 在 DDPM 基线与条件方案稳定后，再比较 DDIM 采样速度、不同 U-Net 容量/分辨率，之后才考虑 LDM/DiT。
- 每次正式实验有唯一 ID，预先记录假设、主指标、模型选择规则和实验预算；尽量一次改变一个主要因素。
