# WBC 无条件 DDPM 评估协议 v1

状态：在 128/256 短程比较和正式训练评估之前预先登记。以下阈值是本项目的操作性 go/no-go 标准，不是临床或领域通用标准；若要修改，必须在查看正式测试结果前记录版本和理由。

## 评估数据与冻结规则

- 使用冻结的 Raabin-WBC split manifest；训练只读 train，checkpoint 选择只用训练/验证信息，最终报告使用 test 一次性评估。
- 正式 checkpoint 按预先固定的更新步数选取；不得依据 test 样本、test 指标或测试集近邻结果挑选 checkpoint。
- 固定并保存正式生成 seed 清单。人工盲评使用至少 200 张生成图和 200 张 test 真图，混排、随机编号并隐藏来源；保留原始评分表和映射表。
- 最终 EMA checkpoint 预定生成 2,000 张图；KID 使用 100 个、每个 1,000 张的子集，使生成侧可从更大的样本池重复抽样。报告样本量与特征维度，不把它描述成大样本稳定估计。
- 盲评尽量由 3 名评审独立完成，其中至少 1 名具备血液形态学评阅经验。若评审人数或资历不足，报告中降低结论强度，不把非专家意见描述成专家判断。

## 人工盲评量表

每张图按 1–5 分评价：可辨认为白细胞、单细胞完整性、核/胞质结构可辨性、染色/背景合理性、伪影严重程度；另标注明显多细胞、细胞截断、纯噪声/空白、疑似重复模板。评审前用真实图像样例校准量表，但不使用正式生成样本调阈值。

主门槛按图像计算：至少 2/3 评审将其“可辨认为 WBC”评分给到 4 或 5 的生成图比例须 ≥80%；至少 2/3 评审认为单细胞主体完整（评分 ≥4）的比例须 ≥80%；至少 2/3 评审认为存在严重伪影（伪影严重程度评分 ≤2）的比例须 ≤15%。伪影严重程度采用反向 1–5 级：1=严重到图像不可用，3=可见但不严重，5=无明显伪影。同时公布各评审原始比例及一致性，不只报告合并结果。

## 分布、覆盖、多样性与记忆化

- 报告 FID/KID 时，分别说明特征网络、输入预处理、真实/生成样本数及置信区间；ImageNet 特征只作为通用视觉参考。没有经验证的 WBC 域特征网络时，不把 FID/KID 作为 go/no-go 单独依据。
- 报告冻结 test 真实图和生成图在特征空间的 precision/recall、density、coverage；同时做真实 test 二分的 real-vs-real 参照，避免把嵌入空间本身的偏差误作模型失败。报告细胞类型覆盖和比例时仅作事后描述，并明确类别来源标签可能不完全可靠。
- 用固定输入预处理对生成图与全部训练图执行 SHA-256/像素完全相同检查、感知哈希筛查及通用 Inception 特征空间 top-5 近邻检索；人工复核哈希筛出的全部候选和特征近邻。任何确认的训练图复制都触发 no-go 并调查；哈希或通用特征近邻命中本身只触发复核，不直接判复制。
- 视觉多样性由盲评者标注重复模板/显著变化不足，并结合特征覆盖结果解释。若盲评发现明显模式坍塌，或特征覆盖显示相对 real-vs-real 参照显著收缩，则不通过；单个未校准的 embedding 分数不能单独决定通过。
- 收齐盲评表和答案映射后，运行 `python -m ddpm.summarize_wbc_blind_review --review-dir <blind_review_v1目录>`。脚本验证评审 ID 与答案键一致，按至少 2/3 投票计算预登记门槛，并输出 JSON/Markdown 汇总；可用 `--expert-reviewer reviewer_01` 记录具备形态学经验的评审（可重复传入）。

## 条件生成 go/no-go

只有同时满足以下条件，才建议进入条件生成：数据使用/引用条件已留档；拆分、配置、checkpoint 与 seed 可追溯；上述三项人工质量门槛通过；未发现确认的训练样本复制；盲评和特征覆盖均未显示明显模式坍塌。任何一项失败或证据不足，都先记录限制并返工/补评，不以 loss 下降或单一 FID 代替质量判断。

通过只表示可开始研究标签控制，不代表疾病图像真实性、病理机制学习或临床用途有效。
